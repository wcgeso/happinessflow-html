01 / 先了解遊戲

《第二人生》在玩什麼？

大家一起擲骰子走棋盤，遇到不同事件時做選擇。

擲骰子走棋盤

輪到你的時候擲骰子，依照點數前進，看看這次會走到哪裡。

抽卡遇到事件

可能遇到工作、房屋、家庭、投資或生活中的突發事件。

做出你的選擇

你要考慮手上的錢和未來的目標，決定要參加、購買、投資或放棄。

測試時請記得：不只看自己畫面，也留意朋友有沒有看到同樣的事件、能不能做出自己的選擇，以及大家是否能順利進入下一回合。
02 / 開始前

需要準備什麼？

人員

  • 建議 4 位玩家，最多 6 位。
  • 另需要 1 位執行師帶領遊戲。
  • 每位玩家準備一支手機。
  • 執行師準備一台電腦顯示共同地圖。

測試前提醒

  • 使用測試用帳號登入。
  • 先確認每個人都能進入同一個房間。
  • 請保留操作畫面或截圖，方便說明問題。
  • 測試時不要害怕做錯，奇怪的地方都值得記下來。
03 / 參考文章與測試方法

文章重點：不要只正常玩，要用不同方式找問題

這篇文章研究的是遊戲測試方法，我們把它改成《第二人生》可以使用的版本。

摘要重點

  1. 先正常玩一次，了解遊戲應該怎麼進行。
  2. 接著用不同的玩家方式去玩，找出平常不容易遇到的問題。
  3. 每次測試設定一個小目標，並記錄看到的情況。
  4. 發現一個問題後，要繼續檢查附近的功能，因為相關問題可能不只一個。
  5. 用錄影、截圖和白話描述，讓開發者可以重現問題。

文章裡的七種玩法

  • 觀光客：正常走完流程，也看看其他選項。
  • 隨意亂試：做一些平常不會做的操作。
  • 專門找碴：集中測試一個功能，想辦法找出問題。
  • 快速遊玩：快速連續完成很多回合。
  • 走冷門路線：測試很少人使用的功能。
  • 畫面檢查：檢查按鈕、視窗、滑動和文字。
  • 問題附近再找：一個地方出錯，就把相關功能一起檢查。

1｜對照《第二人生》的測試策略

平台遊戲原本是在測試關卡、跳躍和操作；《第二人生》則要改成測試「多人一起做事時，大家是否看到同樣的結果」。所以每個策略都要加入：同時操作、重新開啟、完成後換回合，以及金錢結果是否正確。

2｜整理成可執行的測試計畫

  1. 先用 3 位玩家完成一局正常遊戲。
  2. 再分別測試幸福家庭歷程、房市、貸款、保險、定存、工作室和卡片日誌。
  3. 每個功能都試一次正常使用、一次做錯、一次重新開啟後再做。
  4. 安排兩位以上玩家同時擲骰、回覆或購買，觀察是否有人看不到或結果不一致。
  5. 發現問題後，沿著同一功能和相似卡片繼續檢查。
  6. 修正後，使用原本的操作再做一次，確認問題真的消失。

3｜這套方法適合《第二人生》嗎？

適合，但需要加上多人測試。文章的方法很適合用來發現未知問題；不過《第二人生》還要多確認玩家之間的畫面、回合、金錢和事件是否一致。因此「一般人實際遊玩」搭配「多人一起測試」最適合目前階段。
04 / 遊玩順序

請照這個順序測試

1｜進入房間執行師開房，所有玩家加入並完成開局選擇。
2｜正常遊玩輪流擲骰、走棋盤、抽卡並完成事件。
3｜試試特殊情況多人同時操作、重新開啟畫面、再做一次相同動作。
4｜完成一局確認能結算，再開第二局確認可以重新開始。
最重要的原則：先正常玩一遍，知道正確流程後，再試著快速點擊、關閉畫面、重新進入，看看遊戲能不能接著玩。
05 / 試玩清單

這些功能請務必試試看

可以直接勾選。每個項目都完成後，再進入下一項。

開局與回合

  • 每個人都有看到完整的開局選擇。
  • 每個人的幸福值都是正確的初始數字。
  • 輪到誰，誰才能擲骰子。
  • 擲完骰子後，棋子走到正確位置。
  • 完成事件後，可以順利進入下一回合。
  • 重新開啟後，可以回到原本的遊戲進度。

幸福家庭歷程

  • 抽到卡片的人可以先選擇要不要參加。
  • 其他玩家要先擲到 4 點以上，才看到參加選項。
  • 沒有達到條件的人，不會一直重複跳出視窗。
  • 每個人的家庭歷程依自己的進度往下走。
  • 大家同時操作後，畫面沒有消失或卡住。
  • 所有人完成後，抽卡的人可以結束回合。

房屋與金錢

  • 每位玩家都可以嘗試購買房市中的房屋。
  • 兩人同時買同一間時，只有一人成功扣款。
  • 買房成功後，房屋、金錢與貸款都正確。
  • 買房失敗後，不會錯誤扣錢。
  • 放棄購買的房屋會回到房市。
  • 定存、貸款與保險的結果都正確出現。

卡片與畫面

  • 先看到卡片內容，再看到卡片帶來的結果。
  • 卡片說明可以完整滑動查看。
  • 所有需要回覆的玩家都有看到視窗。
  • 卡片日誌有留下剛剛的卡片。
  • 手機畫面可以滑動，按鈕都按得到。
  • 執行師重新開一局後，可以正常開始。
06 / 發現問題時

請用白話記下來

不用猜原因，只要把看到的情況寫清楚。

哪些情況要回報？

  • 卡住 按鈕按不到、不能滑動、不能進入下一回合。
  • 結果不對 金錢變錯、同一筆結果出現兩次、該有的東西沒有出現。
  • 畫面奇怪 視窗消失、重複跳出、朋友看不到或看到不同內容。

回報時請提供

  • 剛剛做了哪些操作？
  • 原本以為會發生什麼？
  • 實際發生了什麼？
  • 還能不能繼續玩？
  • 有截圖或錄影就一起附上。

簡單回報格式

什麼時候發生？日期、約幾點
哪位玩家遇到？玩家 1／2／3
當時在做什麼？例如：幸福歷程按下參加
實際看到什麼？用自己的話描述
能不能繼續？可以／需要重開／完全卡住
附件截圖、錄影或畫面照片
如果整場卡住：先不要一直重複按，也不要急著關掉所有畫面。先截圖或錄影，再通知執行師。
07 / 問題分級

發現問題後，分成 A、B、C 三級

不用分析技術原因，只要看它對遊戲的影響有多大。

等級白話判斷例子怎麼做
A｜最嚴重遊戲完全不能繼續，或結果會造成很大錯誤。整場卡住、不能換回合、金錢被扣兩次、房屋或貸款出現錯誤。先停止操作，截圖或錄影，馬上通知執行師。
B｜需要修正功能結果不對，但還能用其他方式繼續。卡片結果沒有出現、某個按鈕不能用、部分玩家沒有看到訊息。記下操作和結果；如果不影響資料，可以繼續測其他項目。
C｜小問題畫面、文字或操作感覺不順，但不影響遊戲進行。文字太小、視窗短暫閃一下、顏色不明顯、動畫不順。截圖或用文字記下來，測試可以繼續。
不確定時：先按照 B 級回報，並說明「目前還能不能繼續玩」，由執行師或開發者再確認。
08 / 測試完成

什麼情況算完成？

  • 大家都能加入房間並完成開局。
  • 至少正常完成 5 個回合。
  • 試過幸福家庭歷程、房市與至少一種金錢功能。
  • 試過重新開啟後繼續遊戲。
  • 遊戲可以正常結束並進入結算。
  • 再開一局時，沒有帶到上一局的畫面或結果。
  • 所有發現的問題都有留下白話說明和 A／B／C 等級。
給測試夥伴：你的工作不是找出哪裡寫錯，而是告訴我們「玩家做了什麼、看到了什麼、能不能繼續」。這樣就很有幫助了。

09 / 完整提案附錄

完整測試方法與詳細執行內容

前面的內容是一般夥伴直接使用的版本；這裡保留完整提案，方便執行師或開發夥伴深入安排測試。

一、文章重點摘要

這篇文章的核心不是「一直玩遊戲找 Bug」，而是：

讓測試員帶著不同目的與玩家行為去探索遊戲，並用固定時間、錄影、嚴重度分級與問題連鎖追查，提高找錯效率。

主要方法包括：

  1. 先正常玩一次，了解完整流程。
  2. 將測試切成固定時間的小回合。
  3. 使用不同測試策略，模擬不同類型玩家。
  4. 全程錄影並記錄操作與思考。
  5. 發現問題後，繼續測試相關功能。
  6. 對已出錯區域進行「危險街區」深度追查。
  7. 提供測試專用捷徑或管理工具，避免浪費時間重玩前置流程。

文中的七種策略

策略目的
觀光客正常走完整流程，也探索分支功能。
探索性冒煙隨機做不尋常操作，找意外錯誤。
連續犯罪之旅集中破壞某個功能或規則。
垃圾收集者快速連續操作，測試極限與流程銜接。
後巷之旅測試冷門、少使用或隱藏功能。
使用者介面探索專門測試按鈕、彈窗、滑動與版面。
危險街區針對已發現的問題，繼續檢查周邊功能。

文中「先正常玩一次」比較像前置階段，不完全算在七大策略內。

二、對照《第二人生》的適用方式

這套方法很適合《第二人生》，但不能直接照搬。

平台遊戲主要測試

  • 關卡
  • 跳躍
  • 物理碰撞
  • 操作手感
  • 畫面與選單

《第二人生》更重要的是

  • 多人同時操作
  • 遊戲畫面與資料同步
  • 回合狀態
  • 財務交易
  • 卡片事件
  • 斷線重連
  • 玩家權限與資料隔離
  • 重複送出與同時操作
因此應改成：探索性人工測試＋多人一起測試＋本地測試資料驗證。

對應測試方式

文章策略《第二人生》實際測試
觀光客從開房、登入、職業選擇、擲骰、抽卡到結算完整走一次。
冒煙測試快速連點、重新開啟、切換分頁、快速關閉視窗、同時送出。
連續犯罪專門測試房市購買、幸福歷程、企業貸款或保險。
垃圾收集者快速完成多回合，連續擲骰、抽卡、結束回合。
後巷之旅測試執行師工具、重複事件、第二局、離開後重連、舊房間。
UI 探索測試手機滑動、彈窗、按鈕、文字、鍵盤與錯誤訊息。
危險街區發現 H011 同步錯誤後，擴大測試 H011～H016、多人回覆與重連流程。
三、建議的可執行測試計畫

階段 1：正常流程基準測試

使用 3 位玩家＋1 位執行師、本地 Firebase Emulator、每位玩家獨立瀏覽器分頁、執行師一個大地圖分頁，並全程錄影。

  1. 開房。
  2. 三位玩家加入。
  3. 完成職業、目標事業、人生夢想選擇。
  4. 開始遊戲。
  5. 正常擲骰與換回合。
  6. 抽卡、購買、保險、貸款。
  7. 完成幸福歷程。
  8. 遊戲結算。
  9. 同一批帳號重新開第二局。

目的：先確認正常玩家流程是否可以完整完成。

階段 2：核心功能探索

每個主題建議限時 15～20 分鐘。

A. 幸福歷程

  • 抽卡玩家直接選擇參與或放棄。
  • 其他玩家擲骰小於 4。
  • 其他玩家擲骰大於等於 4。
  • 多名玩家同時擲骰。
  • 玩家同時完成回覆。
  • 抽卡玩家最後完成。
  • 非抽卡玩家最後完成。
  • 玩家重新開啟後繼續。
  • 完成後結束回合。
  • 五個階段依玩家個別進度遞進。

B. 房市

  • 多位玩家同時購買同一物件。
  • 購買後房屋從房市消失。
  • 放棄後房屋回到房市。
  • 不同玩家購買不同物件。
  • 檢查失敗後重新嘗試。
  • 重複點擊購買按鈕。

C. 金錢功能

  • 現金剛好足夠與少 1 元。
  • 信貸與企業貸款。
  • 定存與解約。
  • 汽車貸款。
  • 房屋、汽車、醫療保險。
  • 股票買賣。
  • 購買企業或人生夢想。
  • 工作室升級成功、失敗與重試。

D. 重新進入遊戲

  • 玩家重新整理畫面。
  • 玩家關閉後重新登入。
  • 執行師重新整理。
  • 大地圖重新整理。
  • 幸福歷程中重新整理。
  • 擲骰動畫中重新整理。
  • 第二局確認上一局資料不殘留。

階段 3：七種探索策略

策略實際做法
1. 觀光客正常玩完整一局，順便探索所有看到的按鈕與分支。
2. 探索性冒煙快速連點、多分頁同時操作、操作後立刻重新整理、同時關閉與送出、切換玩家帳號、事件結束瞬間再送出一次。
3. 連續犯罪一次只攻擊一項功能，例如房市：兩人同時買同一房屋、反覆點購買、購買後立即重新整理、購買失敗後再操作其他金錢功能、切換玩家後再次購買。
4. 垃圾收集者快速連續完成 10～20 回合，觀察回合是否錯位、舊視窗是否出現、卡片是否重複、金錢是否重複扣除、revision 是否持續遞增。
5. 後巷之旅專測執行師卡片發送、指定下一回合、重複事件、第二局、離開後重連、保險理賠、企業貸款升級與卡片日誌。
6. UI 探索專測手機 390×844、桌面 1440px、彈窗滑動、按鈕遮蔽、錯誤訊息、不可按狀態、鍵盤焦點與多個彈窗。
7. 危險街區例如 H011 出錯後，追查 H011～H016、抽卡玩家與其他玩家、成功與失敗骰值、同時送出、重新整理後重送、最後完成者與財務檢查。

五、這套方法是否適合目前遊戲？

結論：適合，約有 80% 可以直接採用。

最適合直接採用的部分

  • 固定時間測試。
  • 不同玩家行為策略。
  • 全程錄影。
  • 問題區域延伸追查。
  • 測試專用執行師工具。
  • 嚴重度分級。
  • 先正常玩，再進行特殊操作測試。

需要調整的部分

  1. 平台遊戲是單人，《第二人生》必須加入多人一起操作的測試。
  2. 不能只依賴真人遊玩，金錢與權限要用本地測試資料驗證。
  3. 測試單位不能只用「關卡」，應改成「完整事件流程」。
  4. 必須加入斷線、重新整理、切換分頁與第二局測試。
  5. 需要記錄事件、交易結果與遊戲資料前後是否一致。
最終建議順序：正常流程 → 觀光客 → 畫面檢查 → 連續犯罪 → 快速回合 → 後巷功能 → 危險街區追查 → 本地多人測試 → 小規模正式封測。

在幸福歷程、房市交易、企業貸款與斷線重連仍有 A 級問題前，不建議正式全面開放。

這篇文章的方法適合當作「找問題的探索框架」，但《第二人生》是否能正式運行，還必須搭配多人一起操作、資料前後一致與重新進入遊戲的驗收。
