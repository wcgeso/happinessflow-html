# Card Database Audit Report

## Purpose

本文件盤點目前實際使用的卡片資料與卡片效果，確認每張卡是否具備可執行規則。

本次盤點以目前實際被引用的 `src/constants/cards.ts` 為主；`src/constants/cards.ts.new` 為未被主程式引用的草稿副本，不納入正式統計。

- 幸福卡：`H001` - `H046`
- 機運卡：`C001` - `C056`
- 新聞卡：`N001` - `N058`
